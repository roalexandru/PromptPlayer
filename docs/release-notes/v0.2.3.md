## What's fixed

### Diagnostics could open empty

The window would sit on "Loading…" and never fill in, on the one path it exists
for: the automatic open after a launch where the keyboard hook failed to
install. It only fetched its contents once it had been told it was on screen,
and on that path it is opened before it is listening, so the message arrived
before anything could hear it. It now loads its contents on startup regardless.

This was introduced in 0.2.1, alongside the change that stopped it polling in
the background.

### Upgrading

Existing installs pick this up through the built-in updater. Your prompts,
triggers and hotkeys are unchanged.
