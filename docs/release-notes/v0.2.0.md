## What's new

Prompt Player now works as a companion for coding agents as well as for live
demos.

### Use the prompts you already have

Import a project's existing prompt files: Claude Code commands and skills,
Cursor rules, and Continue or Copilot prompt files. `$ARGUMENTS` becomes a
fill-in field, and each prompt keeps the name you already type to invoke it.

### Type it and send it

`Cmd+Enter` (`Ctrl+Enter` on Windows) types the prompt and submits it.

Line breaks now adapt to the target. Most terminals deliver Shift+Enter as a
plain Enter, which submits an agent prompt at its first blank line, so prompts
aimed at a terminal use a backslash continuation instead. Set it per prompt or
for the whole library.

### Multi-step turns

A `<!-- pp:wait 25s -->` line splits a prompt into a sequence: the first
message is typed and sent, then the follow-up goes in after the pause. The kill
switch reaches the sequence while it waits.

### Prompts that know the repository

`$GIT_BRANCH`, `$REPO_NAME` and `$CWD` resolve from the checkout you are
working in. Expressions can also call `git("rev-parse --short HEAD")` once
enabled in config, limited to read-only subcommands.

### Fill in the blanks before it fires

Choices and tab stops such as `${1|aggressive,conservative|}` and `${2:main}`
are answered inline in the palette before it dismisses, rather than silently
taking the first option.

### A palette that remembers

With no search query the palette lists what you used most recently. "Save what
I just typed" turns something you improvised into a stored prompt.

### Run a demo from a setlist

Put prompts in order and fire the next one with a single hotkey, so recalling a
trigger word is never the thing standing between you and the next slide. The
tray menu shows the cue position and can advance or rewind it.

### Take control mid-prompt

Pause a running playback, narrate what is on screen, then resume where it
stopped. Speed it up or slow it down while it types. Unlike the kill switch,
nothing is discarded.

### More convincing typing

The engine models false starts: type part of a word, hesitate, delete it,
retype. Frequent on the Thoughtful CEO profile, absent from Fast Presenter.

### Share prompts from a GitHub repository

Point at a public repository of `.pp.md` files and its prompts appear in your
library, read-only.

Because a shared prompt gets typed into whatever you have focused, they arrive
disabled until you enable them, any `hotkey:` they declare is ignored, and
updates are fetched but never applied on their own: you see which prompts
changed and decide. A repository can describe itself with a
`promptplayer-pack.yaml`, including a minimum app version.

### Safer by default

- Refuses to type into password fields, and into anything that cannot accept
  text at all.
- The palette is hidden from screen capture again, on both macOS and Windows.
- The tray icon flashes red when the kill switch fires, so an abort is visible.
- Optional auto-disable after a set number of minutes armed.
- On an extended desktop the palette stays on your own display rather than
  following the pointer onto the projector.

### Diagnostics

A diagnostics window reports version, permissions and keyboard-hook status,
runs a self-test that types into itself, and can repair macOS Accessibility
approval. The tray icon carries a badge when the hook is not running or an
update is waiting.

### Settings that stick

Keep Awake now has a duration and releases itself when it expires. Restoring
the armed state and Keep Awake at launch are both opt-in.

Cross-cutting settings live in `promptplayer.yaml` next to your prompts. Every
global hotkey is rebindable there and takes effect without a restart.

### Upgrading

Existing installs pick this up through the built-in updater. Your prompts,
triggers and hotkeys are unchanged.
