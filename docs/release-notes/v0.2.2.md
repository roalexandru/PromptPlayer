## What's fixed

A hotfix for three things that went wrong on screen.

### The menu bar icon is back

Whenever Prompt Player had something to tell you — the keyboard hook not
running, or an update waiting — the icon disappeared from the menu bar and left
a bare orange dot in its place. The badge was being drawn in a way that stopped
macOS recolouring the glyph for the menu bar, so the icon was painted in its own
colour: black, on a dark menu bar.

The icon now stays visible in either appearance, and the badge is a smaller dot
in the corner rather than something the size of the icon itself. On macOS the
dot takes the menu bar's own colour instead of orange, which is the trade for
having the icon render at all; on Windows it stays orange.

### The tray menu no longer cuts itself off

Opening **Keep Awake for…** added its choices to a menu that never grew, so the
list was cut off part-way through the last row and the items below it were
unreachable. The menu now resizes for anything that changes its height.

### The Diagnostics window scrolls properly

Scrolling ran rows underneath the window's own close button. The title now stays
put at the top and the content passes behind it.

Its **Open Accessibility Settings** button was also a green that fought the
amber warning it sits inside; it now uses the same accent as the rest of the app.

### Upgrading

Existing installs pick this up through the built-in updater. Your prompts,
triggers and hotkeys are unchanged.
